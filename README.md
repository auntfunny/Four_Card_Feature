## Overview

This was a simple responsive design challenge. It was to use flexbox and grid to create a different and responsive design for mobile and desktop, and I included a design for tablet as well.

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size

## My process

I wrote the HTML and then designed the mobile app using Tailwind CSS. I then moved onto the desktop version and made the necessary adjustments to design. I finally did the tablet version last, changeing the layout to fit the tablet sizes.

### Built with

- Mobile-first workflow
- CSS Tailwind


### What I learned

  This was good practice with Grid, because I have not been able to work much with it. It helped me to learn a little more about how to design
Grid and change it depending on the size of the screen.

```html
<section class="grid grid-cols-1 md:gap-4 lg:gap-8 md:grid-cols-2 md:grid-rows-[264px_264px] lg:grid-cols-3 lg:grid-rows-1 lg:items-center">
```

  This is the code I used to go from one to three columns, with only two columns and a square design in the tablet format.

### Continued development

  I want to keep learning how to better use Grid and how to create more responsive designs using Grid and FlexBox.
